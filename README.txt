MY CHAOS BLANKET — UPDATED APP

Files: index.html, manifest.json, icon.svg, sw.js. Upload all four files to the root of your GitHub Pages repository (my-chaos-blanket).

The upgraded app migrates data from the old myChaosBlanket.v1 key into the new project structure when it first loads in the same browser, including row history, colours, and any stitch notes found in the saved data. Still, export a backup from the old app before replacing files whenever possible.

Features: multiple projects/statuses, per-row hook and notes, charts by colour/stitch/hook, stitch notes library, stitches-to-try list, shared yarn wish list, full JSON export/import. Data is stored locally in the browser on the device.
