MY CHAOS BLANKET — iPhone web app

WHAT'S INCLUDED
- Seven stitch choices, including textured Blueberry stitch
- Yarn colour swatches and ability to add colours
- Stitch notes section to save instructions and reminders separately for each stitch
- Row entry form, date field, editable/deletable history
- Running total rows, number of logged sections, colours used, and rows by stitch
- Automatic saving in the browser on the current device
- JSON backup export/import and copyable text summary
- Home Screen web-app manifest and offline cache support

IMPORTANT
This is a static web app, not yet hosted online or published to the App Store. For the best iPhone Home Screen experience, host the files on an HTTPS static host (for example GitHub Pages), then open the published URL in Safari and choose Share > Add to Home Screen. If offered, enable “Open as Web App”.

DATA AND BACKUPS
Data is stored in browser localStorage on the device where you use the app. It does not automatically sync to another device. Use Export backup regularly and keep the JSON file somewhere safe. Import backup replaces the current data, so export the current data first if you need both copies.

HOW TO HOST ON GITHUB PAGES
1. Sign in to GitHub and create a new public repository named my-chaos-blanket.
2. Upload all four files: index.html, manifest.json, sw.js, icon.svg (README.txt is optional).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select the main branch and /(root), then Save.
5. Wait for the Pages URL to appear. Open that URL in Safari on your iPhone.
6. In Safari, tap Share (square with arrow), then Add to Home Screen. If available, turn on Open as Web App, then tap Add.

If GitHub's screens differ, check its current Pages instructions. Do not share private yarn notes or backup files publicly; only upload the app files to the public repository.
